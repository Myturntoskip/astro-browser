# 🚀 Astro Browser

O **Astro** é um navegador web minimalista, elegante e veloz, construído sobre o motor **Chromium** utilizando o ecossistema **Electron**. Este projeto foi desenvolvido de forma nativa e híbrida para correr com a máxima performance tanto em **Ubuntu (Linux)** como em **Windows**.

---

## ✨ Funcionalidades Principais

*   **🌐 Navegação por Múltiplas Abas:** Abre, fecha e alterna entre vários sites em simultâneo com gestão de processos isolada.
*   **🔍 Barra de URL Inteligente:** Deteta se escreveste um site real ou palavras comuns, redirecionando automaticamente para o Google se for uma pesquisa.
*   **🌗 Modo Claro & Modo Escuro:** Interface dinâmica com transição de cores fluida e persistência de preferência.
*   **⭐ Histórico & Favoritos:** Painel lateral interativo para guardar as tuas páginas preferidas e consultar onde navegaste.
*   **🚀 Ajuste de Performance Cross-Platform:** Corre de forma fluida com aceleração por hardware no Windows e traz correções automáticas de estabilidade gráfica para o Linux.

---

## 🛠️ Como Executar em Modo de Desenvolvimento

Se quiseres testar ou modificar o código localmente no teu computador:

1.  Garante que tens o **Node.js** instalado.
2.  Clona o repositório e entra na pasta:
    ```bash
    git clone https://github.com
    cd astro-browser
    ```
3.  Instala as dependências necessárias:
    ```bash
    npm install
    ```
4.  Inicia o navegador:
    ```bash
    npm start
    ```
