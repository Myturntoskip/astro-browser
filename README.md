# 🚀 Astro Browser

O **Astro** é um navegador web minimalista, elegante e veloz, construído sobre o motor **Chromium** utilizando o ecossistema **Electron**. Este projeto foi desenhado de forma híbrida para correr com a máxima performance em **todos os grandes sistemas operativos**.

---

## ✨ Funcionalidades Principais

*   **🌐 Navegação por Múltiplas Abas:** Abre, fecha e alterna entre vários sites em simultâneo com gestão de processos isolada.
*   **🔍 Barra de URL Inteligente:** Deteta se escreveste um site real ou palavras comuns, redirecionando automaticamente para uma pesquisa no Google (com suporte completo a caracteres especiais).
*   **🌗 Modo Claro & Modo Escuro:** Interface dinâmica com transição de cores fluida e persistência de preferência.
*   **⭐ Histórico & Favoritos:** Painel lateral interativo para guardar as tuas páginas preferidas e consultar onde navegaste.
*   **🚀 Ajuste de Performance Cross-Platform:** Corre de forma fluida com aceleração por hardware no Windows/Mac e traz correções automáticas de estabilidade gráfica para o Linux Ubuntu.

## 📦 Downloads e Instalação (Instaladores Oficiais)

Acede à aba [Releases](https://github.com) no lado direito do repositório para descarregar a versão mais recente estável do Astro:

*   **🍏 macOS (Apple):** Descarrega o ficheiro **`.dmg`**. Dá dois cliques para abrir o disco virtual e arrasta o Astro para a tua pasta de *Aplicações*. *(Nota: Na primeira execução, clica com o botão direito do rato em cima da app e escolhe "Abrir" para saltar o aviso do Gatekeeper).*
*   **🖥️ Windows:** Descarrega o ficheiro **`.exe`** e executa-o. O instalador automático vai configurar o teu navegador e criar os atalhos no ambiente de trabalho num segundo.
*   **🐧 Ubuntu / Linux:** Descarrega o ficheiro **`.deb`** e instala-o clicando com o botão direito no ficheiro e executando-o com o Centro de aplicações. 


---

## 🛠️ Como Executar em Modo de Desenvolvimento

Se quiseres testar ou modificar o código localmente no teu computador:

1.  Garante que tens o **Node.js** instalado.
2.  Clona o repositório e entra na pasta:
    ```bash
    git clone https://github.com/Myturntoskip/astro-browser
    cd astro-browser
    ```
3.  Instala as dependências necessárias:
    ```bash
    npm install
    ```
4.  Inicia o navegador:
    ```bash
    npm start
    ```
